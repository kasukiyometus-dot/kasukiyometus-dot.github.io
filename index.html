CORE TOPICS

핵심 학습 주제

01 / DNS
DNS
Domain Name System

도메인 이름을 IP 주소로 변환하는 인터넷의 전화번호부. 계층적 구조와 캐싱 메커니즘을 이해합니다.

  • DNS 계층 구조 (Root · TLD · Authoritative)
  • 쿼리 흐름 — Recursive vs Iterative
  • A / AAAA / CNAME / MX 레코드 타입
  • TTL과 DNS 캐싱 전략
  • 실습: nslookup / dig 명령어
02 / TCP/IP
TCP/IP
전송 제어 프로토콜 / 인터넷 프로토콜

데이터를 신뢰성 있게 목적지까지 전달하는 인터넷의 근간. 4계층 모델과 핸드셰이크를 실습으로 파악합니다.

  • TCP/IP 4계층 모델 개요
  • IP 주소 체계 & 서브넷 마스크
  • TCP 3-Way Handshake
  • 혼잡 제어 & 흐름 제어 알고리즘
  • 실습: Wireshark 패킷 캡처 분석
03 / HTTP
HTTP
HyperText Transfer Protocol

웹 통신의 언어. 요청-응답 구조부터 최신 HTTP/2·3의 성능 개선 사항까지 실제 요청으로 확인합니다.

  • HTTP 메서드 (GET / POST / PUT / DELETE)
  • 상태 코드 의미 (2xx · 3xx · 4xx · 5xx)
  • 헤더 구조 — 쿠키, 캐시, 인증
  • HTTPS & TLS 핸드셰이크
  • 실습: curl · 브라우저 개발자도구

실습 커리큘럼

01
nslookup / dig — DNS 쿼리 추적
실제 도메인의 DNS 레코드를 조회하고, Recursive 쿼리 과정을 단계별로 추적합니다.
nslookup · dig
02
Wireshark — 패킷 캡처 & 분석
TCP 3-Way Handshake 과정을 직접 캡처하여 각 패킷의 플래그와 시퀀스 번호를 분석합니다.
Wireshark
03
curl — HTTP 요청·응답 직접 확인
다양한 HTTP 메서드와 헤더를 직접 작성하고, 서버 응답 상태 코드를 분석합니다.
curl · httpbin
04
브라우저 DevTools — 네트워크 탭 탐구
실제 웹사이트 로딩 과정에서 DNS Lookup → TCP → HTTP 흐름 전체를 시각적으로 확인합니다.
Chrome DevTools
